# TraceRoot interview questions

Answer using the repository evidence. Separate measured results from planned features.

1. **Why is this agentic?** The Investigator selects bounded read-only evidence actions and updates hypotheses; the tool-less Auditor judges citations. See [Investigator](../traceroot/agents/investigator.py), [Auditor](../traceroot/agents/auditor.py), and [OWASP agent security](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html).
2. **Why does the Auditor have no tools?** It independently checks supplied evidence and can demand more, without changing the investigation. See [Auditor](../traceroot/agents/auditor.py).
3. **What differs among LangGraph, CrewAI, and AutoGen here?** Only orchestration; the bounded core and approvals remain common. See [adapters](../traceroot/orchestrator/), [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence), [CrewAI Flows](https://docs.crewai.com/en/concepts/flows), and [AutoGen AgentChat](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/tutorial/index.html).
4. **How do pause and resume work?** Discuss checkpoints, cursors, and cumulative budgets; current cloud state is not durable shared storage. See [workspace control](../traceroot/workspace_control.py) and [LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence).
5. **What stops arbitrary writes?** Read-only tool schemas, exact human approval, disposable sandbox, and deterministic verification. See [tool schemas](../traceroot/agents/schemas.py) and [OWASP least privilege](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html).
6. **How is a root cause supported?** A runtime or reproduction observation plus independent confirming subsystem evidence, checked for contradictions by the Auditor. See [monitor](../traceroot/autonomous_monitor.py).
7. **What recovery was measured?** Grade-band cases improved 0/3 to 3/3. The staging pipeline completed 10/10 stages but ended succeeded_partial, so clean end-to-end recovery is not established. See [README](../README.md) and [roadmap](limitations-roadmap.md).
8. **How are cost and latency bounded?** Model/tool call caps, timeouts, token accounting, and estimated cost events. See [workspace metrics](../traceroot/workspace_metrics.py).
9. **How would RAG/tool failures be correlated?** Join trace IDs across application, retrieval, model, provider, and tool spans; redact sensitive attributes. See [OpenTelemetry GenAI attributes](https://opentelemetry.io/docs/specs/semconv/registry/attributes/gen-ai/).
10. **What does MCP add?** Standard tool exposure, while authorization and least privilege remain application responsibilities. See [MCP authorization](https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization).
11. **Why are executor and verifier not agents?** They enforce fixed policies and run tests; AI roles make constrained judgments. See [architecture](../README.md#architecture).
12. **What remains before an Azure public launch?** The private Azure revision is healthy; authenticated HTTPS, external homepage verification, shared durable state, remote sandbox jobs, and tested recovery monitoring remain. See [Azure Container Apps authentication](https://learn.microsoft.com/en-us/azure/container-apps/authentication).
